# B2B AUTOMATION RUNBOOK

Current V1+ execution path:

Research → evidence capture → qualification → decision-maker → contact verification → personalization → policy/authority check → authorized execution → verification → follow-up.

Never invent contacts, evidence or personalization.

External communication is not universally prohibited. It may execute only when the effective owner/bot authority policy explicitly delegates the capability and scope.

Execution state must remain distinguishable:

`INTENT → AUTHORIZED → EXECUTED → VERIFIED`

A failed or unknown execution must not be recorded as SENT/VERIFIED without evidence.

Use `03_PROTOCOLS/AIOS_AUTOMATION_PROTOCOL_V1.md` and `03_PROTOCOLS/BOT_AUTHORITY_PROTOCOL.md` as the current canonical policy sources.
